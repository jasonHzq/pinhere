# Pinhere Chrome Web Store listing

## Name

Pinhere

## Short description

Select a webpage DOM element and create an agent-ready issue with its screenshot and exact browser context.

## Detailed description

Pinhere hands the live webpage directly to your AI coding agent.

When a layout, copy, or interaction bug appears during review, you no longer need to juggle screenshots, URLs, and directions to “the button in the top right.” Activate Pinhere, select the exact element, and keep its page URL, DOM location, editable screenshot, and issue description together in one structured defect.

Key capabilities:

• Exact DOM selection with CSS selector, XPath, element structure, viewport, and position.
• Visible-tab screenshot capture with cropping and annotation before submission.
• A private workspace with OPEN, IN PROGRESS, and DONE issue states.
• Agent-ready handoff through the Pinhere Skill, CLI, and stable API.
• User-initiated access: Pinhere reads the current page only when you activate the extension, start the picker, and submit an issue.

Built for independent developers, AI-native product teams, product and design reviews, QA, and frontend teams that want to remove the back-and-forth from visual bug reports.

Privacy: Pinhere does not read browser history, cookies, passwords, or form values. The page URL, limited DOM context for the selected element, and visible-tab screenshot are sent over HTTPS to the user's private workspace only after explicit submission. Full policy: https://pinhere.dev/en/privacy
