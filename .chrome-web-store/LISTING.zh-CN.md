# Pinhere Chrome Web Store 商店资料

## 名称

Pinhere

## 简短说明

圈选网页 DOM，连同截图和上下文创建结构化缺陷，交给 AI Coding Agent 领取、修复并回写结果。

## 详细说明

Pinhere 把网页现场直接交给 AI Coding Agent。

当你在验收网页时发现样式错位、文案错误或交互异常，不必再截图、复制链接、描述“右上角那个按钮”。点击 Pinhere，直接圈选出错的页面元素，即可把页面 URL、DOM 定位信息、可编辑截图和问题描述收进同一条结构化缺陷。

核心能力：

• 精准圈选 DOM：保存 CSS Selector、XPath、元素结构、视口和位置，减少反复确认。
• 截图编辑：自动捕获当前可见区域，支持裁剪和标注后再提交。
• 私有工作区：按项目管理 OPEN、IN PROGRESS、DONE 状态，截图需要账号鉴权才能访问。
• Agent-ready：通过 Pinhere Skill、CLI 和稳定 API，让 Coding Agent 领取 Issue、更新状态并写回修复结果。
• 主动读取：Pinhere 仅在你点击扩展、启动圈选并提交时读取当前页面，不持续监控浏览活动。

适合：

• 使用 AI Coding Agent 的独立开发者和产品团队
• 产品、设计和测试人员进行网页验收
• 需要减少截图、地址、选择器和任务描述往返的前端团队

使用方式：

1. 登录 Pinhere，并在工作台创建项目和页面来源。
2. 在需要反馈的网页点击 Pinhere，选择“圈选页面问题”。
3. 点击具体元素，调整截图、标题和描述，然后创建缺陷。
4. 复制修复 Prompt，或让已配对的 Coding Agent 自动领取和处理。

隐私说明：扩展不会读取浏览历史、Cookie、密码或表单输入值。页面 URL、选中元素的有限 DOM 上下文和可见区域截图仅在用户主动提交后通过 HTTPS 上传到其私有工作区。完整说明：https://pinhere.dev/zh-CN/privacy
